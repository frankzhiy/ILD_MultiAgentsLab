# 诊断流程改造与验证记录

本次目标是修复会诊任务不明确、具体候选遗漏、解释范围及并存关系错误、知识检索缺失、证据接口不一致和收束失效。现有输入就是本次任务的全部患者资料，必须据此形成当前最支持的诊断意见及必要的有限鉴别；不补造患者事实，也不以资料不足或诊断未完成退出任务。

## 已实施的流程

1. 前端提供“进一步明确诊断”“判断是否属于ILD”“复核已有诊断”三个模板，默认第一项；允许补充问题，批量病例可逐例覆盖模板。API、运行快照、四科和主持人使用同一任务。重试继承原任务，修改任务须创建新运行。
2. 四科在正式意见生成时同时给出原子判断及证据引用。删除判断乘证据的全组合标注流程，程序验证并回填引文。影像命题输入明确提供对应evidence_ids。
3. 主持人先按患者表型检索疾病知识，再基于患者原文独立生成候选；随后按候选判别问题检索，审查四科判断并形成全病例结论。每次整合增加一次候选生成请求，讨论轮数沿用既有预算；检索和引用校验不调用临床模型。
4. 候选记录其层级、患者依据、解释范围、未解释内容及判别信息。主持人对每个候选恰好审定一次；待讨论候选必须指向具体开放议题。局部病变、形态描述与全局病因分别比较。
5. 结果记录具体诊断、暂定诊断意见、有限具体鉴别或推理待讨论。删除 input_limited 结果；缺少确证通过确定程度表达。暂定判断允许如实记录模式、大类或发现层级，不能因此强迫具体疾病，也不能把有依据的疾病推断降为异常罗列。缺失信息可说明对结论的影响，不是完成前提；现有资料尚可推进的推理必须路由议题。主要诊断与其他开放议题分别处理。
6. 前端展示任务、诊断层级、候选取舍、解释范围、判断的不确定性及待讨论推理，支持回看候选原文引用。新报告必须包含候选探索和诊断目标复核；旧结果仍可作为历史产物读取和下载，不能直接成为新流程的完成结果。

## 知识库

删除仅保留推荐/定义/阈值的抽取方式及固定阶段查询接口。使用成熟句段切分库和BM25库，融合向量及词项召回；患者长文本按多个窗口检索，不截掉后段记录或后序候选。新索引保留段落、正文和图表说明，在参考文献起点停止入库。版本为clinical_passages_v3，共989段。索引、目录和患者任务写入规则快照。

## 虚构病例真实模型检查

以下为纠偏前的历史验证记录，保留原结果，不代表当前固定输入下的诊断契约。

使用项目配置的APIYI模型，仅传输虚构病例及合成专科意见。资料稀少病例完成整合，状态为input_limited，层级为finding，没有硬造具体疾病，给出形态、生理和病因判别缺口；候选与整合共耗时181.98秒。混合形态病例首次输出被收束校验拦截，随后修复了主诊断与其他问题的缺口范围。复验完成，独立候选形成CPFE和IPF，最终为specific_diagnosis、syndrome、CPFE；IPF保留为纤维化组分的疾病候选，而非CPFE的互斥替代解释，并明确病因及进展资料限制；候选与整合共耗时255.90秒。

## 固定输入诊断纠偏（2026-11-03）

此前将“不编造患者事实”扩展成“资料不齐就诊断未完成”，并以 input_limited 状态、强制资料缺口及前端警示固化了这种行为。本次移除该退出路径。任务说明、共享协议、呼吸科诊断形成、独立候选与主持人收束统一要求：基于现有输入给出实质判断，不等待新增患者资料；既往诊断保留来源并参与推断；不确定性通过暂定判断、信度和有限鉴别表达。证据编号校验、候选逐项审查、未记载不视为阴性、条件结果不作事实的约束保留。

暂定判断解除必须达到疾病/综合征层级的校验，以免删除 input_limited 后反而迫使模型编出疾病；明确具体诊断与具体疾病鉴别仍须如实达到疾病或综合征层级。无可推进议题时以已形成当前诊断意见结束。历史产物不改写，需要重新运行才会应用新契约。

本次验证：后端408项、前端59项测试通过，生产构建和差异格式检查通过。回归覆盖旧退出状态被拒绝、暂定判断不强制具体疾病或资料缺口、无具体候选仍能形成当前意见并投影报告、旧产物不混入当前结果。未调用真实模型重新运行病例，尚未验证此次提示调整的实际诊断表现。

## 输出校验与重试纠偏（2026-11-03）

运行记录确认，病理及影像的正式意见反复触发两类错误：不可评价判断填写了诊断置信度，以及“未直接阅片”等表达触发全文正则拦截。完整重生成会让已经修好的字段再次出错。

- 删除专科、主持人、讨论及最终报告中的措辞正则硬拦截；表达要求仍由提示词引导，不因关键词而重新调用模型。初始意见中的跨科冲突关键词拦截一并删除，避免将否定句误判为冲突。
- 四科正式输出的严格Schema提前约束可评价性与置信度；不可评价判断只允许unknown。无病理材料时的专用Schema直接固定这两个字段，JSON fallback契约也明确该关系。运行时仍核对字段一致性。
- 四科各阶段沿用已有局部edits修复机制处理必要错误，不重新生成整份意见；证据来源、证据适用范围、引用解析及指南引用检查保留。

后端416项测试通过，包含四科局部修复保留原判断、严格Schema合法字段组合、措辞不触发重试、现有未知或越权证据仍被拒绝。已保存的病理及影像第二次响应离线通过正式输出校验，影像复验沿用原有可诊断证据范围；未新增模型请求，未据此宣称全流程运行时长达标。本次修改不压缩各科原有分析阶段或输出长度。
