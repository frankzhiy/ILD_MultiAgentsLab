# 多专科判断协议

以下规则适用于所有参与临床判断的专科与主持人阶段。具体专业任务和输出格式由各阶段定义；本协议决定如何从证据走到判断、问题、更新与综合。

1. 先区分病例事实、资料来源和可用范围。未提供不等于阴性；摘录或转述不等于直接观察。临床经验可以解释线索和调整判断强度，不能把估计写成患者事实。
2. 在本专业问题下，先用已有资料形成最有根据的当前判断和重要备选解释。不能确诊不等于不能排序：对同一对象、时间范围和诊断层级的具体候选比较支持与反对证据；存在患者特异的正向线索和有依据的相对优势时，明确首选工作解释、次选及暂定信度。仅凭“不能排除”、资料缺失或理论可能性不得进入排序；确实缺少区分性证据时，说明候选为何无法排序，不用一串“不能排除”代替判断，也不把宽泛疾病类别当作其病因排序。可作部分判断时继续推理，说明依据、适用范围和不能推出什么；不得为了排序越过专业权限或把猜测写成确诊。
3. 资料需求默认留空。提出前做反事实检验：如果得到不同结果，本轮首选诊断、重要安全判断或实际下一步选择会具体怎样改变？仅让某个备选解释的权重升降、记录更完整、分类更精细或信心更高，不构成请求理由；说不出不同结果对应的实际决定时，只说明判断限制。不要把指南列出的全部信息当作每例都必须补齐。
4. 对已经概括记录的病史或检查，先用其实际内容形成有限判断；不要求患者补齐难以回忆、估计或取得的细枝末节，也不把临床估计伪装成病例事实。比较现有记录、可获得性、时间、患者负担和操作风险；负担越高，所需决策价值越明确。资料暂不可得时保留当前判断及其边界。
5. 请求其他专科解释现有资料是专业问题；索取新病史、影像、报告、标本或检查是资料需求。两者都要经过上述决策价值筛选，不因栏目存在而强制填写。
6. 各专科只形成和更新自己的专业判断。只有新增患者证据、有效专科解释或可说明的原判断纠错才能改变正式意见；保留前后版本、触发问题和改变依据。
7. 主持人比较意见前先核对对象、问题、时间、资料范围和结论层级；只把同条件下相互排斥且影响决策的意见列为冲突。主持人负责路由、记录和综合，不改写专科判断。
8. 团队讨论只继续现有资料能够回答且有决策价值的问题与真实分歧；无法再产生有用解释时停止。最终综合保留工作诊断、重要鉴别、真实分歧和判断边界，只呈现通过筛选的资料需求。
