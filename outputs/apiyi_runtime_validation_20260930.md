## 根因与修复

- 病例分段固定使用普通 JSON，未使用已配置的严格结构约束，历史 101-IPF 输出出现非法来源标签。改为按服务能力选择严格 JSON Schema；不支持该能力的客户端仍使用普通 JSON。
- 局部修复要求输出先通过模型结构校验，因此重复审阅编号等结构错误触发整份重写并持续失败。允许完整 JSON 对象的结构校验错误进入既有局部修复流程；重复编号错误提供具体编号和下标。
- 102-IPF 将资料需求编号填入议题链接，错误信息未标明位置，模型反复修改其他链接。校验现在返回错误字段路径、非法编号及可用议题编号；提示明确区分资料需求编号和议题编号。
- 102-IPF 同一议题重复派发给呼吸科，模型修复时误删影像科任务。校验现在列出重复专科与下标、缺失和多余专科，要求合并重复问题并保留其他科任务。
- 主持人 CLI 测试意外访问真实指南库，与正在运行的工作台争用本地索引。该合成测试隔离指南检索；真实运行继续使用项目指南库。

历史连接中断已有受限重试及回归检查覆盖，本次未修改传输代码。真实运行中的若干证据摘录错误由现有校验重试纠正，没有放宽逐字证据校验。
